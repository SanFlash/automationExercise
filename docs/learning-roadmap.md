# Learning roadmap

1. JavaScript modules and async/await.
2. Playwright page, locator, action and assertion fundamentals.
3. Repair a locator using the trace viewer.
4. Compare spec, page object and locator module.
5. Study `test.extend()`, fixture lifecycle and isolation.
6. Separate data from test steps with factories.
7. Coordinate journeys through business flows.
8. Test documented API contracts.
9. Map Gherkin features to step definitions, World and hooks.
10. Inspect screenshots, traces and HTML/JSON/JUnit reports.
11. Read CI logs and download artifacts.
12. Advance into controlled authentication, stable test seeding and flaky-test analysis.
